# nozzle-isen

nozzle-isen 是理想气体等熵喷管核算的 Go 命令行内核：读取一个 JSON 算例（滞止温度 T0、滞止压力 p0、热容比 γ、气体常数 R、面积比 A_e/A*、喉道面积 A*，可选设计膨胀支与背压 pb），用同一 γ 与同一滞止状态完成喉道壅塞判定、面积–马赫反解与壅塞/未壅塞质量流量核算。输出喉道状态（壅塞时 M*=1，p*/p0=(2/(γ+1))^{γ/(γ−1)}，T*/T0=2/(γ+1)）、出口两支马赫数与压力/温度比、是否壅塞及理由、质量流量 qm；给定背压时按设计出口压比报告过膨胀/欠膨胀并明确「未建模正激波」。输入边界：T0≤0、p0≤0、γ≤1、R≤0、A_e/A*<1、喉道面积≤0 一律 stderr 明文报错并以非零退出码结束；γ 距 1 过近（γ−1<1e-3）返回 error 而非除零；面积比反解 M 用阻尼牛顿、初值按亚/超两支选取、迭代上限用尽报不收敛；背压过高（pb/p0 超过声速压比 p*/p0）时喉道无法壅塞，流量改用出口等熵落到背压的亚声速解，绝不按壅塞公式。本仓只做喷管等熵与壅塞核算，不做孔板差压计量（orifice-iso）、不做有压环网稳态（pipe-network），也没有网页与遥测大屏。

- 输入：一个 JSON 算例文件，字段 `t0`、`p0`、`gamma`、`r`（缺省 287.0 空气）、`area_ratio`、`throat_area`、`branch`（可选 "subsonic"/"supersonic"，缺省给两支并标明）、`back_pressure`（可选，Pa）；`example/gamma14.json` 为 γ=1.4、面积比 2 的标准算例
- 输出：`design` 子命令打印滞止状态、喉道（壅塞时 M*=1 与临界比）、出口两支（马赫、p_e/p0、p_e、T_e/T0）、壅塞判定与理由、质量流量与所用公式；给定背压时加过膨胀/欠膨胀报告与「未建模正激波」提示；末尾附自检行（面积比闭环、压力比互推、壅塞通量与 M=1 通量一致）
- 边界：等熵关系、面积–马赫函数与质量流量共用同一 γ 与同一滞止状态；M=1 代入面积公式得 A/A*=1；同一滞止下提高 p0，壅塞流量按比例升而马赫分布不变；出口等熵压力比与该支马赫的等熵压力公式互证；γ→1 极限不做除零，过近报错

## 构建 / 运行 / 测试

```text
go build ./...                       # 编译（纯标准库）
go test ./...                        # 全部测试（gas / isentropic / nozzle / main）
go run . design example/gamma14.json # 缺省两支：亚声速 M≈0.306、超声速 M≈2.197，壅塞，qm≈2.364 kg/s
```

命令反例（应 stderr 报错并非零退出）：

```text
go run . design example/gamma14.json # 先改成 area_ratio=0.5 再跑，面积比必须 ≥1
go run . design example/gamma14.json # 先改成 gamma=1.0 再跑，热容比必须 >1
go run . design example/gamma14.json # 先改成 p0=0 再跑，滞止压力必须为正
```

指定设计膨胀支或背压的算例（branch="supersonic" 只给超声速支；back_pressure 高于 p*/p0×p0 时进入未壅塞路径，流量用出口等熵落到背压的亚声速解）。
